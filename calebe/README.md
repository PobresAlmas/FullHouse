# Entrega de código — Calebe

Esta pasta reúne recortes históricos do código do FullHouse organizados por sprint, com especificações, documentação de implementação e testes unitários relacionados. O objetivo é facilitar a análise e a comparação das soluções e das dificuldades técnicas.

## Conteúdo

- [Sprint 1 — Despensa](sprint-1/README.md): módulo de despensa, persistência, interface e testes.
- [Sprint 2 — Lista de compras](sprint-2/README.md): lista compartilhada por residência, OpenSpec, interface, API e testes.
- [Sprint 3 — Insights, segurança e testes](sprint-3/README.md): painel financeiro, correções de autorização/autenticação e incremento de testes unitários.
- [Análise comparativa](ANALISE_COMPARATIVA.md): resumo dos domínios, decisões e desafios para discussão.

Os arquivos foram copiados de commits do Git identificados nos READMEs de cada sprint. Mantive o código das funcionalidades e os documentos Markdown; retirei schemas e migrações do banco, manifests, capturas de tela e testes e2e/integração. Os recortes preservam os caminhos originais do projeto, mas não são aplicações independentes.
